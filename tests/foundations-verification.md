# 基础课程验收

下面是需要逐项执行的清单，不代表已通过。构建和预览检查不能代替真实客户端输入/显示验证。

| 步骤 | 预期 |
| --- | --- |
| 从空 SourceRoot 运行构建脚本 | 克隆锁定提交，三项目构建成功，不修改服务器目录 |
| 指向已有但不同提交/有改动的依赖目录 | 明确失败，不覆盖本地修改 |
| 安装依赖与插件后重启测试服 | 启动日志包含插件启用，无缺失依赖错误 |
| 普通玩家执行 `cement give` | 拒绝，要求 ServerConfigs 权限 |
| 管理员存活时执行 `cement gallery` | 三行中文；12 秒后消失 |
| 切换角色、死亡、断线、卸载 | 本示例提示消失，无持续协程或事件回调 |
| 接受建议按键/自行改键 | 按键只在符合条件时触发；不能假定自动绑定 |
| 普通硬币/空手按键 | 没有 `[Cement] Use`，没有教学冷却 |
| `cement give` 后手持硬币按键 | 一条 Use 日志，5 秒冷却，持续按/重复按不能跳过 |
| 将硬币丢弃，再由另一人拾取 | 同一 serial 的 Drop/Transfer；剩余冷却保留 |
| HUD 切换隐藏/显示 | 隐藏只影响界面；再次显示恢复当前状态 |
| `cement clear` | 画廊关闭；持有硬币时状态 HUD 仍显示 |
| 清空背包/销毁拾取物 | 不再显示，序列号登记在下一轮检查移除 |
| 回合重置 | 旧登记与冷却清空 |
| 无 HSM 启动 | 日志提示缺少 HSM，give 与按键仍可用，gallery 给出说明 |
| 背包满时发放 | 明确失败，不登记不存在的物品 |
| 不同分辨率、亮背景、背包与观战 UI | 文字可读，无意外换行或原生 UI 冲突 |

记录格式：日期、源码提交、游戏/LabAPI/HSM 版本与 DLL 哈希、测试端口、步骤、实际结果、截图/日志路径。
日志提交前去除玩家身份及机器路径；不要上传整个服务器日志。
